# Three storylines

## 1. One session, five real screens (used)
Device: the result first. Form: one continuous take, cut only on key presses.
Frame 0 is a close-up of a scraped article; the camera pulls back to the whole
two-pane screen, rewinds to the feed list, then walks the real task: open a feed,
scrape a page, search it, focus it, then open the link and image palettes, then
read a single Wikipedia page from the shell. Look: near-black ground, the eight
ANSI colours, hairlines, no chrome. Sound: key ticks and typing only.

## 2. The web, stripped
Device: type carries the argument. Form: one frame that rebuilds itself.
The raw HTML of a page fills the frame; each beat deletes markup until only
prose is left, then the prose becomes the app's own column, then the column
splits back into panes. Look: same ground, but no UI until the halfway point.
Sound: a rising bed. Rejected: it sells the scraping, not the reader.

## 3. Terminal as the whole world
Device: a moment in someone's day. Form: match cuts between feeds — a feed
count in the panel title becomes a post count becomes a byte count becomes a
line number. The viewer watches numbers travel between panes. Look: the panel
borders as the only structure. Sound: a count-up tick on each number.
Rejected: it hides the features behind a conceit.
